# Qwen Usage

Follow applicable user and workspace instructions before changing this project.

- Read only the dedicated Qwen quota tab through its scoped BB browser lease.
- Never read or copy cookies, tokens, passwords, other tabs, or browser profiles.
- Never send chat messages, purchase upgrades, use reset cards, or change providers.
- Missing, stale or invalid data must be unavailable, never fabricated zero usage.
- Keep local runtime logs, connection descriptors and credentials out of version control.
- Run the tests, typecheck and native bb plugin build before shipping changes.
